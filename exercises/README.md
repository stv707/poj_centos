# CentOS Stream 10 Enterprise Administration Lab Exercises

Direktori ini mengandungi fail rujukan amali bagi bengkel pentadbiran sistem Linux CentOS Stream 10:

- `centos-admin/backup-kes.sh`: Skrip sandaran berjadual dokumen kehakiman POJ.
- `centos-admin/case-monitor.conf`: Fail konfigurasi contoh servis pemantauan kes.
- `centos-admin/sudoers-sample`: Contoh polisi keselamatan kebenaran granular sudoers.
